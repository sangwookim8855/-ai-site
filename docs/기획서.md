# 서비스 기획서: 도로공학 AI 학습 도우미

- 배포 URL: https://road-ai-helper.vercel.app

## 1. 서비스 목적

도로공학은 토공, 포장, 배수처럼 용어와 기준이 많아 처음 배울 때 이해하기 어렵습니다. 이 서비스는 학생이 궁금한 개념을 입력하면 AI가 쉬운 말로 설명해 주고, 이해했는지 바로 확인할 수 있는 퀴즈까지 만들어 주어 혼자서도 복습할 수 있게 하는 것을 목적으로 합니다.

## 2. 타겟 사용자

- 도로공학, 토목공학을 처음 배우는 대학생
- 시험이나 과제 전에 개념을 빠르게 복습하고 싶은 학생
- 교재나 강의 자료의 용어가 어려워 쉬운 설명이 필요한 입문자

## 3. 페이지 구성

한 페이지 안에서 상단 메뉴로 각 섹션으로 이동하는 구조이며, 모바일에서는 메뉴가 ☰ 버튼으로 바뀝니다.

| 메뉴 | 내용 |
|---|---|
| 홈 | 서비스 소개와 시작하기 버튼 |
| 개념 설명 | 개념을 입력하면 AI가 설명 (AI 기능) |
| 퀴즈 | 주제를 입력하면 AI가 객관식 문제 3개 생성 (AI 기능) |
| 이용 안내 | 사용 방법과 유의사항 |

## 4. 핵심 기능

1. **AI 개념 설명**: 정의, 핵심 포인트 3가지, 쉬운 예시 1개를 순서대로 설명합니다.
2. **AI 퀴즈 생성**: 객관식 문제 3개(보기 4개)와 정답, 해설을 한 번에 제공합니다.
3. **반응형 화면**: 데스크톱과 모바일 모두에서 사용할 수 있습니다.

## 5. AI 기능 입력, 출력, 실패 처리 기준

### 입력
- 사용자가 텍스트 입력칸에 도로공학 개념 또는 주제를 입력합니다.
- 입력 길이는 100자 이내이며, 앞뒤 공백은 제거합니다.
- 기능 종류(개념 설명 또는 퀴즈)는 어느 섹션의 버튼을 눌렀는지에 따라 정해집니다.

### 출력
- AI가 생성한 한국어 텍스트를 결과 칸에 표시합니다.
- AI 답변은 학습 참고용이며, 정확한 기준은 교재와 도로설계기준을 확인하도록 안내합니다.

### 처리 과정
1. 사용자가 버튼을 누르면 화면이 서버(`/api/generate`)에 요청을 보냅니다.
2. 서버가 입력을 검사한 뒤 환경 변수에 저장된 키로 AI API를 호출합니다.
3. AI의 답변을 화면으로 돌려보내 결과 칸에 표시합니다.
4. 처리 중에는 버튼을 비활성화하여 중복 요청을 막고 "AI가 답변을 만드는 중입니다..." 문구를 보여 줍니다.

### 실패 처리 기준

| 상황 | 처리 방식 |
|---|---|
| 입력이 비어 있음 | "주제를 입력해 주세요." 안내, AI 호출 안 함 |
| 입력이 100자 초과 | "입력은 100자 이내로 해 주세요." 안내, AI 호출 안 함 |
| 지원하지 않는 요청 | "지원하지 않는 기능입니다." (400 오류) |
| AI 서비스에서 오류 응답 | "AI 서비스 오류가 발생했습니다. (코드 번호)" 표시 |
| AI 응답이 25초 이상 지연 | "AI 응답이 지연되고 있습니다. 잠시 후 다시 시도해 주세요." 표시 |
| AI가 빈 응답을 돌려줌 | "AI가 답변을 만들지 못했습니다. 다른 표현으로 시도해 주세요." 표시 |
| 서버 환경 변수 없음 | "서버 설정 오류입니다. (환경 변수 없음)" 표시 |
| 서버에 연결 불가 | "서버에 연결할 수 없습니다. 잠시 후 다시 시도해 주세요." 표시 |
| 그 외 예상하지 못한 오류 | "알 수 없는 오류가 발생했습니다." 표시 |

모든 실패 상황에서 화면이 멈추지 않도록 오류 문구를 결과 칸에 보여 주고, 버튼을 다시 사용할 수 있게 복구합니다.

## 6. 보안 및 운영

- API 키는 코드에 적지 않고 Vercel 환경 변수로 관리하며, 키 파일은 `.gitignore`로 저장소에 올라가지 않게 합니다.
- 사용자 입력은 화면에 글자(text)로만 표시하여 악성 코드 삽입을 막습니다.
